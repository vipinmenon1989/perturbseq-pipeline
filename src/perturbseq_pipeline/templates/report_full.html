2. Pair-guide QC

Guide features are scaffold-specific (<design id>:<A|C>). For each scaffold slot separately the strongest feature must reach min_umi = {{ cfg.guides.min_umi }} UMIs and satisfy the dominance rule (top guide UMI + {{ pseudocount }}) / (second guide UMI + {{ pseudocount }}) ≥ {{ cfg.guides.dominance_ratio }}. A cell becomes a strict primary construct pair only when both slots pass, the two features share a documented construct id ({{ pair_reference_name }}) and the construct is targeting–targeting (pair_targeting) or NTC–NTC (pair_non_targeting, the primary control). Designed targeting+NTC constructs form the targeting-plus-NTC sensitivity class (pair_targeting_plus_ntc, class ambiguous, excluded from primary testing). Same-target A/C combinations that are not constructs (same-target inferred pairs), two different targets (dual-target ambiguity), several strong features in a slot (scaffold ambiguity), one resolved slot (incomplete pair) and every other non-designed combination (unresolved pair) stay in the object as ambiguous and never enter primary perturbation testing. The single-guide diagnostic (top guide of the whole cell) is computed for comparison only and drives no result.

4. Perturbation strength

For every target whose transcript is measured in the expression matrix, the transcript's log-normalised expression is compared between strict primary targeting pairs and designed NTC pairs (primary control). Two-sided Kolmogorov–Smirnov test (plus one-sided Mann–Whitney), log2FC of de-logged means with pseudocount, BH-FDR within lane × control × stratum.

Control definitions. ntc = designed NTC–NTC constructs (pair_non_targeting); other = strict pairs of all other targets (secondary control, reported in the tables only).
Exact hit rule. fdr_ks < {{ cfg.perturbation.fdr_alpha }} and log2fc < {{ cfg.perturbation.max_log2fc_for_hit }}, with ≥ {{ cfg.perturbation.min_cells_per_target }} target cells and ≥ {{ cfg.perturbation.min_control_cells }} control cells. Raw FDR is reported as fdr_ks; neg_log10_fdr = -log10(max(fdr_ks, 1e-300)).
Strata. primary_pair_targeting (strict pairs, the only stratum used for hit calls) versus the sensitivity strata single_guide_plus_ntc_constructs_only, sensitivity_incl_targeting_plus_ntc and sensitivity_incl_same_target_not_designed.
